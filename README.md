# Adaptive Ticket Pricing — Backend

Spring Boot backend powering real-time ticket pricing and booking.

## Features
- JWT Authentication
- Ticket booking APIs
- Adaptive pricing engine
- MySQL + JPA
- Concurrency handling

## Run Locally
docker compose up -d
mvn spring-boot:run

## API
- /api/auth
- /api/events
- /api/tickets

Frontend demo is available in the `master` branch.
